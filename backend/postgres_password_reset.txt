# PostgreSQL Password Reset Guide
# If you forgot your PostgreSQL password, follow these steps:

# Method 1: Using Windows Services
# 1. Open Windows Services (services.msc)
# 2. Find "postgresql-x64-17" service
# 3. Stop the service
# 4. Edit pg_hba.conf file (usually in C:\Program Files\PostgreSQL\17\data\)
# 5. Change "md5" to "trust" for local connections temporarily
# 6. Restart PostgreSQL service
# 7. Connect without password and reset it

# Method 2: Command line reset (run as Administrator)
# First stop PostgreSQL service
net stop postgresql-x64-17

# Start PostgreSQL in single-user mode
# Navigate to PostgreSQL bin directory and run:
# postgres --single -D "C:\Program Files\PostgreSQL\17\data" template1

# Then in the postgres prompt:
# ALTER USER postgres PASSWORD 'new_password';
# \q

# Start service again
net start postgresql-x64-17

# Method 3: Reinstall PostgreSQL (if needed)
# Download from https://www.postgresql.org/download/windows/
# During installation, set a memorable password
